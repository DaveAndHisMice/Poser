Clean

Clean the tracked positions before anything else uses them: the 3D view, kinematics, clustering and every export then work on the cleaned data, and exports record these settings so etho.py cleans new data the same way. Applying clears clustering results.

× robust scale

Why clean when PCA already discards noise: PCA removes only the noise outside the kept components, and tracking noise is spread across them (on the noisy four-mouse example the kept PCs still hold 75% of it). More importantly, the switching linear dynamics models frame-to-frame steps, where the body's motion is small and white noise is not: there the noise outweighed the movement 1.6 to 1, and cleaning brought it to 0.6 to 1. Swaps and outlier jumps are large single-frame steps that look like state changes.

Export

Clusters: the etho-clusters 1.0 format (one JSON file): every animal's state per frame (1-based), its bouts and PC scores, plus the model (transition matrix, each state's flow field A, b, noise and fixed point), the PCA (variance, loadings, feature names) and the feature settings. Report: a PDF with the ethogram, time budget, bouts, transitions, the PCA, the states in PC space, per-state movement and social measures, average poses and a plain-language summary of each state (built in the browser; the first export fetches the jsPDF library). Notebook: the same analysis as Python code; unzip and run all cells (needs numpy, pandas, matplotlib); it reads the clusters file and the pose data shipped beside it and summarises the behaviour in each state. Script: this run's settings, PCA and states as an etho-model file, plus etho.py and a one-cell notebook that applies the same model to new pose data with the same skeleton, so its states mean the same behaviour (needs numpy, pandas; PCA runs only).

Clusters: the etho-clusters 1.0 format (one JSON file): every animal's state per frame (1-based), its bouts and PC scores, plus the model (transition matrix, each state's flow field A, b, noise and fixed point), the PCA (variance, loadings, feature names) and the feature settings. Report: a PDF with the ethogram, time budget, bouts, transitions, the PCA, the states in PC space, per-state movement and social measures, average poses and a plain-language summary of each state (built in the browser; the first export fetches the jsPDF library). Notebook: the same analysis as Python code; unzip and run all cells (needs numpy, pandas, matplotlib); it reads the clusters file and the pose data shipped beside it and summarises the behaviour in each state.
